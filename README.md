# Riley Carney — Personal Site

> Source code for [rileycarney.github.io](https://rileycarney.github.io)

Personal portfolio and professional landing page for Riley Carney — Mathematician | AI & IT Professional based in Seattle, WA.

## About

This is a single-page static site built with vanilla HTML, CSS, and JavaScript. No frameworks. No build tools. Just clean, fast, accessible code hosted on GitHub Pages.

## Sections

- **Hero** — Introduction, photo, stats, and CTAs
- **About** — Bio, links, and professional philosophy
- **Skills** — Automation, AI, methodologies, and tooling
- **Certifications** — 6 credentials including CSPO, LinkedIn Learning AI certs
- **Projects** — Public repo and gists (PowerShell automation)
- **Writing** — Published LinkedIn Pulse articles
- **Experience** — Career and education timeline
- **Contact** — LinkedIn and GitHub connect links

## Tech Stack

- HTML5 (semantic, accessible)
- CSS3 (custom properties, Grid, Flexbox, animations)
- Vanilla JavaScript (IntersectionObserver, GitHub API)
- GitHub Pages (zero cost hosting)

## Deployment

This repo is configured for GitHub Pages at `https://rileycarney.github.io`.

```
Settings → Pages → Source: Deploy from branch → main / (root)
```

## Local Development

No build step needed. Just open `index.html` in a browser:

```bash
# Option 1: Direct open
start index.html

# Option 2: Simple local server (Node)
npx serve .

# Option 3: VS Code Live Server extension
```
